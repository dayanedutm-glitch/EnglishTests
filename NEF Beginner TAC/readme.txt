1. MINIMUM SYSTEM REQUIREMENTS

* Web browser
    Windows® - requires Internet Explorer 6 or above
    Mac® - requires Safari 1 or above
    Linex – requires Mozilla® 1.1 or above
* Adobe Reader 5.0 or higher, or a compatible reader
* Microsoft Word 97 or higher, or a compatible package


2. RUNNING THE APPLICATION

Windows
* Insert the New English File Beginner Test and Assessment CD-ROM into your CD-ROM drive.
* Double click on 'My Computer'
* Double click on 'nef' CD icon
* Double click on the 'start_here.htm' icon

Mac
* Insert the New English File Beginner Test and Assessment CD-ROM into your CD-ROM drive.
* Double click on 'NEF' CD icon that appears on your desktop
* Double click on the 'start_here.htm' icon

Linex/Guadalinex
* Insert the New English File Beginner Test and Assessment CD-ROM into your CD-ROM drive.
* Mount the disk on to the desktop.
* Double click on 'NEF' CD icon
* Right click on the icon 'start_here.htm and choose to 'open with Mozilla'.


3. TECHNICAL SUPPORT

If you experience any problems with the New English File Beginner Test and Assessment CD-ROM, please check that your machine matches or exceeds the minimum system requirements in point 1 above and that you are following the steps outlined in point 2 above.

If these do not help, do the following:
* Check our website for further information: http://www.oup.com/elt/multimedia/
* Email us with your query at: elt.cdsupport.uk@oup.com. Be sure to provide the following information:
* Version of browser (eg Internet Explorer)
* Operating system (e.g. Windows 98)
* Amount of RAM
* Processor speed
* Description of error or problem
* Actions before error occurred
* Number of times the error has occurred
* Is the error repeatable?
